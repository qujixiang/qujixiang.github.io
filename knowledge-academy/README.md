# Knowledge Academy

本地知识学习项目。用 HTML 课件的形式把复杂知识讲清楚，目标是「零基础能看懂，看完能自己讲出来」。

当前科目：**金融**。

## 设计原则

1. **先直觉，后定义**：每个概念先用生活场景建立直觉，再给严谨定义。
2. **一页一个核心**：每章只回答一个问题，不堆概念。
3. **能算的都能动手**：复利、债券价格、估值，全部配可交互计算器。
4. **每章都有出口**：章末小测验 + 术语卡，学完能自测。
5. **不写正确但没用的内容**：所有例子用真实场景，不用「假设一家公司甲」。

## 单章课件规范

每章是一个独立目录，内含 `index.html`，必须包含以下 8 个区块：

| 区块 | 内容 | 目的 |
|---|---|---|
| ① 本章目标 | 3 条「学完你能……」 | 建立预期 |
| ② 开场故事 | 一个真实场景或反直觉问题 | 制造好奇 |
| ③ 核心概念 | 2-4 个概念，每个配生活类比 | 建立理解 |
| ④ 图解 | SVG 示意图或交互组件 | 降低抽象度 |
| ⑤ 常见误区 | 3 条错误认知 + 纠正 | 防踩坑 |
| ⑥ 90 秒测验 | 3-5 道题，即时反馈 | 检验掌握 |
| ⑦ 术语卡 | 本章术语中英对照 + 一句话解释 | 可复习 |
| ⑧ 下一章钩子 | 一句话引出下章 | 保持连续 |

## 技术约束

- 纯静态 HTML + CSS + 原生 JS，无构建步骤，双击即可打开。
- 不引入外部 CDN，离线可用。
- 图表优先用 SVG 手绘或 Canvas，不引入图表库。
- 移动端可读：最小字号 16px，正文行宽不超过 72 字符。

## 学习路径

课程分三层，建议按顺序学：

- **核心路径（0–13 章）**：建立完整的金融直觉和工具认知，约 6 小时。
- **进阶路径（14–22 章）**：读懂公司、管理风险、个人实战，约 5 小时。
- **拓展路径（23–25 章）**：金融科技与量化，数据从业者优先，约 2 小时。

## 进度记录

`assets/js/progress.js` 用 `localStorage` 记录每章完成状态，键名格式 `ka:finance:ch01`。首页和课程页读取后渲染进度条。
