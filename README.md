# qujixiang.github.io

个人学习站点。

## 内容

| 路径 | 说明 |
|---|---|
| [`knowledge-academy/`](knowledge-academy/) | Knowledge Academy：本地知识学习课件 |
| [`knowledge-academy/finance/`](knowledge-academy/finance/) | 金融课：26 讲，从零基础到能自己判断 |

## 使用

直接访问 <https://qujixiang.github.io/knowledge-academy/> 。

所有课件是纯静态 HTML，无构建步骤、无外部依赖，可离线打开。

## 本地开发

```bash
git clone git@github.com:qujixiang/qujixiang.github.io.git
cd qujixiang.github.io
python3 -m http.server 8000
# 打开 http://localhost:8000/knowledge-academy/
```
